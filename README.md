# Nom de projet non-définitif : GENESIS
Un site web est un réseau social privé à destination des partenaires de militaires (tout corps d'armes confondus). Il est encapsullé afin de pouvoir être une PWA (Progressive Web Application) afin que les utilisateurs puissent l'installer sur leurs smartphones malgré son indisponibilité sur les différents stores.


## 🚀 A propos de moi, qui suis-je ?
Actuellement en formation, future titulaire du Titre Professionnel Développeur Web et Web Mobile (niveau 5), obtenu auprès du GRETA-CFA d'Arles.
Au cours de ma formation, j'ai appris à concevoir et développer des applications web complètes, de l'interface utilisateur (front-end) à la partie serveur et base de données (back-end).
🛠️ Compétences
Front-end : HTML5, CSS3, JavaScript, design responsive, Node.js
Back-end : PHP, SQL, gestion de bases de données
Outils : Git / GitHub, méthodologie de gestion de projet(SCRUM), WordPress(autodidacte)

💛 Pourquoi ce projet ?
Je suis la partenaire d'un légionnaire. Je connais donc de l'intérieur cette vie particulière : les longues absences, les missions, l'éloignement, les non-dits, et le sentiment d'isolement que peuvent ressentir celles et ceux qui restent.
Ce projet est né d'un constat simple : les partenaires de légionnaires ont besoin d'un espace qui leur soit dédié.
Mon objectif est de créer une safe place : un lieu bienveillant et sécurisant où les partenaires peuvent :

🤝 Échanger avec des personnes qui vivent la même réalité
💬 Trouver du soutien, sans jugement
📚 Accéder à des informations et ressources utiles
🌱 Se sentir moins seul·e au quotidien

Ce projet me tient profondément à cœur, car il allie mes compétences techniques à une cause personnelle : prendre soin de cette communauté souvent invisible.
